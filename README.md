# Дунай УКВ

Шпаргалка для радиообмена на Дунае. Берёт услышанную фразу или свой текст и собирает передачу на языке другой стороны: шлюз, обгон, синий щит, осадка, бедствие.

Это не радиостанция. В эфир само ничего не уходит.

## Как открыть у себя

```bash
npm install
npm run dev
```

Сайт будет на [http://localhost:8080](http://localhost:8080).

Перевод и микрофон ходят в xAI. Для этого в окружении сервера нужен `XAI_API_KEY`. Без ключа фразы из картотеки и по буквам всё равно работают.

Микрофон: нажать «Микрофон», разрешить доступ, сказать фразу, нажать «Стоп».
